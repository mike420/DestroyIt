[size=6][b]DestroyIt[/b][/size]

Destroy boats, carts, battering rams and catapults straight away with the hammer's remove tool. The base game already knows when a boat or cart could be removed, but switches it off, so everyone ends up taking an axe to them. This turns it back on. There is also a Demolish key that destroys everything you built within a radius around you, after asking you to confirm.

[size=5][b]Features[/b][/size]

[list]
[*]Destroy [b]boats[/b] with the hammer when nobody is on board.
[*]Destroy [b]carts[/b] with the hammer when nobody is pulling them.
[*]Optionally only when the chest is empty. A private chest must always be empty.
[*]Choose boats, carts, both, or neither, from the in-game settings panel (F7).
[*]Destroy [b]battering rams[/b] and [b]catapults[/b] with the hammer when nobody is using them.
[*][b]Demolish[/b]: press a key ([b];[/b] by default) to destroy everything you built within a radius around you. It first shows how many pieces it would destroy, and you press the key again to confirm. It follows the hammer's rules (your own pieces, no-build zones, wards) and the boat and cart settings.
[*]Skips ValheimRaft boats, which handle their own removal.
[/list]

[size=5][b]Settings[/b][/size]

[list]
[*][b][b]Enable Plugin[/b][/b] (default On): Turns the plugin on. Needs a restart.
[*][b][b]Require Crafting Station[/b][/b] (default Off): If On, a piece can only be destroyed, with the hammer or the Demolish key, when its crafting station (such as the workbench) is near you. That is the game's own rule. If Off, you can destroy pieces wherever you are. Synced with the server.
[*][b][b]Allow Destroy For[/b][/b] (default Both): Boats, carts, both or neither.
[*][b][b]Require Empty Container[/b][/b] (default On): The chest must be empty before it can be destroyed. Synced with the server.
[*][b][b]Allow Destroy Siege Weapons[/b][/b] (default On): Battering rams and catapults can be destroyed with the hammer.
[*][b][b]Key[/b] (Demolish)[/b] (default [b];[/b]): Destroys everything you built within the Radius. Any key, or a key with modifiers.
[*][b][b]Require Confirmation[/b] (Demolish)[/b] (default On): The first press shows how many pieces, and you press the key again within 5 seconds to confirm.
[*][b][b]Radius[/b] (Demolish)[/b] (default 20): How far around you, in metres, the Key destroys.
[/list]

[size=5][b]Translations[/b][/size]

The translation files are in [b]BepInEx/config/DestroyIt/Translations/<Language>/DestroyIt.json[/b]. Edit them, or add a language, and restart the game.

[size=5][b]Multiplayer[/b][/size]

[list]
[*]The server must have the mod too. With it installed you can only join servers that also run it. Players without the mod can still join that server. The major version must match the server's (1.x with 1.x).
[*][b]Require Crafting Station[/b] and [b]Require Empty Container[/b] are the server's in multiplayer (only an admin can change them). The other settings are your own.
[/list]

[size=5][b]Installation[/b][/size]

### Automatic Install
Plugin is created to be installed with r2modman or Gale.
For Nexus downloads you will need to install manually.
### Manual Install
[list]
[*]Un-zip and drag the [b]DestroyIt[/b] folder in your [b]BepInEx/plugins/[/b] folder.
[/list]
